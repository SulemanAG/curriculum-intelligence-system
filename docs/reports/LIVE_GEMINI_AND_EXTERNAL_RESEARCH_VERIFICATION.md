## 1. ExternalResearchService & Google Search Grounding Implementation

The `ExternalResearchService` (`org.curriculumai.orchestration.research.ExternalResearchService`) coordinates live web research by querying the Google Gemini REST API with search grounding enabled.

### Request Construction

The service sends an authenticated `POST` request to:
```
https://generativelanguage.googleapis.com/v1beta/models/{geminiModel}:generateContent?key={geminiApiKey}
```

#### Payload Structure
```json
{
  "contents": [
    {
      "parts": [
        {
          "text": "<System Directive>\n\nSearch and Research Target: <Prompt Query>"
        }
      ]
    }
  ],
  "tools": [
    {
      "google_search": {}
    }
  ]
}
```

### Response Parsing and Grounding Metadata Extraction

The Google Gemini response payload contains `candidates[0].groundingMetadata.groundingChunks`. The service extracts:
1. `groundingChunks[i].web.uri`: The Google Search Grounding redirect URI (`https://vertexaisearch.cloud.google.com/grounding-api-redirect/...`).
2. `groundingChunks[i].web.title`: The human-readable title of the indexed web page.
3. `domain`: Host domain parsed via `java.net.URI`.
4. `candidates[0].content.parts[0].text`: The synthesized research summary generated by the grounded model.

### Error Handling & Resilience
- **Configurable Timeout:** Configured via `app.research.timeout-seconds=75` to accommodate live Google web crawling latency (typically 20–45 seconds).
- **Retry Mechanism:** Implements a 2-attempt retry loop with exponential backoff on transient `SocketTimeoutException` or HTTP `503`.
- **Honest Failure Reporting:** If the network is unavailable or credentials are invalid, the service sets `successful = false` and provides the exact exception message without fabricating fallback text.
